# План автоматизации по тестированию приложения веб-сервиса “Путешествие дня”

## Цель:
## Провести автоматизацию тестов для приложения веб-сервиса “Путешествие дня”.

## Позитивные сценарии покупки тура:

### Сценарий 1. Покупка тура с помощью карты со статусом APPROVED:
1.	В браузере открываем страницу веб-сервиса http://localhost:8080/;
2.	Нажимаем кнопку “Купить”;
3.	В появившемся окне вводим валидные данные: 
- номер карты: 4444 4444 4444 4441;
- месяц: в формате двух цифр от 01 до 12, текущий или последующий;
- год: в формате последних двух цифр, текущий или последующий, но не более 5 лет от текущего;
- Владелец: Ivan Makarov;
- CVC/CVV: в формате трех цифр – 123;
4.	Нажимаем кнопку "Продолжить";

**Ожидаемый результат:**
В браузере поверх формы появляется окно с сообщением: "Успешно. Операция одобрена Банком.". 
В базу данных приложения вносится соответствующая запись.

## Перечень используемых инструментов с обоснованием выбора:

1.	Java 11 – Язык программирования, работающий на различных операционных системах.
2.	IntelliJ IDE - Удобная среда разработки с поддержкой Java и различных фреймворков. Отличная интеграция с GitHub. Большой набор расширений и плагинов для тестирования.
3.	Git/GitHub - Распространенная система контроля версий. Удобно ввести репозиторий проектов, есть возможность параллельной разработки.
4.	JUnit5 – Фреймворк для быстрого написания тестов, поддерживающий Java и IntelliJ IDEA.
5.	Gradle - Система сборки проекта, при помощи которой возможно управление подключёнными зависимостями и генерация отчётов о тестировании.
6.	Lombok - библиотека для Java, позволяет с помощью аннотаций автоматически генерировать шаблонные методы кода (get, ser, конструкторы и т.д.), что позволяет уменьшить количество кода.
7.	Selenide – Удобный фреймворк для автоматизированного тестирования веб-страниц и веб-приложений, используемый при написании тестов.
8.	JavaFaker – Простой фреймворк для генерации случайных тестовых данных.
9.	Docker - Система контейнеризации. Позволит развернуть работу приложения с базами данных на MySQL и PostgreSQL, а также работу эмулятора банковских сервисов, написанного на Node.js. 
10.	Dbeaver – Программа для подключения и работы с базами данных приложения. Поддерживает работу с различными СУБД: MySQL, PostgreSQL и другими. 
11.	Allure Report – Простая и удобная система подготовки отчётов с наглядной и информативной визуализацией отчётов.
## Перечень и описание возможных рисков при автоматизации
1.	Отсутствие технической документации к приложению вызывает сложности с запуском и настройкой веб-сервиса.
2.	Сложности подключения к двум различным СУБД и проверка корректности их работы: MySQL и PostgreSQL.
3.	Сложности в написание автотестов при отсутствии тестовых меток в приложение, отсутствие технических требований к заполнению полей форм, отсутствие информации о корректной работе БД приложения.
4.	Любые изменения структуры веб-сервиса приложения могут привести к неработоспособности написанных автотестов.

## Интервальная оценка с учётом рисков (в часах):

1.	Планирование автоматизации тестирования (составление плана тестирования, настройка окружения для запуска веб-сервиса и баз данных, ознакомление с функционалом приложения, написание сценариев тестов, оценка рисков при написание тестов) - 24 часа.
