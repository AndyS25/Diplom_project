## Отчет по итогам автоматизированного тестирования
___

### Краткое описание
Проведена автоматизация тестирования комплексного сервиса, взаимодействующего с СУБД и API Банка - приложеня веб-сервис "Путешествие дня"

Тестирование проведено в соответствии с [планом автоматизации тестирования](https://github.com/AndyS25/Diplom_project/blob/main/documents/Plan.MD)

### Количество тест-кейсов

**Всего:** 42 тест-кейса
- Успешных: 34 тест-кейсов - 80,95%
- Неуспешных: 8 тест-кейсов - 19,04%
